# LegacyRim
LegacyRim is an attempt to expand on the Great Modlist LoreRim. The intent is to keep every visual and difficulty tweak possible from LoreRim and add in the extended gameplay from exploring every nook and cranny of the world to collect and fill the museum.

Install requires a full install of the LoreRim modlist to start. Then You will install LegacyRim in it's own folder, and copy everything directly into the LoreRim install location.

Current Builds label all the folders as [NoDelete], to make it easier for updating LoreRim without erasing all the work (I learned that the hard way early on). There is still a lot not blended together. But it should be fully playable. Any Problems report here or the Nexus LegacyRim Repo Page https://www.nexusmods.com/skyrimspecialedition/mods/184848

0.5.0.2 ASA, ToK, &amp; LOA Mostly blended together. All Aetherium deposits are LOA ones, ignots for all three can be crafted from that ore.
You 3 stage craft each line of the ASA models with LOA and ASA ignots, only the last is museum displayable. And you need to do related quests to be able to craft. The lower tier line (steel) will have LOA enhancements, the upper ASA enhancements.
TOK now uses LOA models and will see increases in base Armor rating. Enchants and Recipes are updated, but still incomplete and very unbalanced. Going cross eyed trying to decide exactly how to distribute the enchants so moving on to something else for a bit. suggestions welcome.
