# LegacyRim
### Description
LegacyRim is an attempt to expand on the Great Modlist LoreRim. The intent is to keep every visual and difficulty tweak possible from LoreRim and add in the extended gameplay from exploring every nook and cranny of the world to collect and fill the museum.  

### Main features
The Core is LoreRim and Legacy of the Dragonborn  

### Before you start  
This is still Very much a WIP. It is playable, but there is still a lot that needs properly mixed in. For example, LoreRim is heavily built around Requiem 5, which already has most of Immersive Weapons Built in. But because Requiem has different FormIDs Those versions are considered completely different items by the game and are not displayable in the Museum. These will be intermingled so eventually you only find one FormID version that's displayable in the Museum.

### Installation need to know
There are Multiple types of Patch ESPs. 
LotD Merges are step 1 level  
These combine multiple esps from the many compatibility patch collections into one for the named location revamp. These don't specifically require a full LoreRim setup, but do require USSEP, LegacyoftheDragonborn.esm and whatever of the LotD officially supported Displayable mods that particular patch targets.  
Loreqtificitated are step 2 level  
These at first are built with the named esp run through the Unofficial Reqtificator Lite plus a couple other synthesis plugins. Then they are by hand blended with LoreRim setup to integrate the mod to LoreRim. The ultimate idea is to eventually merge LoreRim LotD, most often objects that are in both will take the stats and placements from LoreRim with an FORMID and appearance that are compatible with LotD official patches. These all require a full LoreRim install and the named mod possibly with a few bug patches for such mods. They don't specifically require anything else from a LotD setup. They will eventually include the step 1 level patches blended in.  
Consistency are step 3 level  
These are the last level patches that will merge together the step 2 level esps. These require a full LoreRim install and most likely a full LotD setup.
